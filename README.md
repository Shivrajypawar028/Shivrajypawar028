## 🚀 Featured Projects

### 🎣 AI-Based Phishing Detection System
**Category:** Cybersecurity / AI

**Overview:**
A cybersecurity and machine-learning project focused on identifying phishing content by analyzing its textual characteristics. Phishing attacks rely on deceptive messages to trick users into revealing sensitive information or interacting with malicious content, and this project explores how machine learning can help flag such content.

The system applies text preprocessing and feature extraction techniques to convert raw text into a form suitable for classification, then uses a Logistic Regression model to categorize content as potentially phishing or legitimate. Explainability was an important focus, aimed at understanding *why* a piece of content was classified a certain way rather than treating the model as a black box.

**Problem:** Phishing attacks use deceptive messages and content to trick users into revealing sensitive information or interacting with malicious links/content.

**Solution:** Uses machine-learning techniques to analyze textual characteristics of content and classify it as potentially phishing or legitimate.

**Technologies:** Python, Machine Learning, NLP, TF-IDF, Logistic Regression

**Key Concepts:** Text preprocessing, feature extraction, TF-IDF vectorization, classification, model training, explainable AI

**What I Learned:** How to preprocess and vectorize text data, apply TF-IDF for feature extraction, train and evaluate a classification model, and reason about model explainability in a security context.

### 📡 Wi-Fi Deauthentication Attack — Security Experiment
**Category:** Cybersecurity / Networking (Educational)

**Overview:**
An authorized educational lab experiment exploring Wi-Fi deauthentication attacks and how they exploit weaknesses in wireless management frames. The experiment was conducted to understand wireless network security from a defensive standpoint — how these attacks disrupt legitimate connections, why they're possible, and what that means for network security awareness.

This project deepened my understanding of Wi-Fi security weaknesses and the importance of defensive measures like frame protection standards.

**Problem:** Wireless networks can be disrupted through deauthentication attacks that exploit unprotected management frames, posing a real security concern for Wi-Fi networks.

**Solution:** An authorized, controlled lab experiment to study how deauthentication attacks work and what they reveal about wireless network vulnerabilities.

**Technologies:** Networking concepts, Wi-Fi protocols

**Key Concepts:** Wireless management frames, Wi-Fi security weaknesses, network security awareness, defensive implications

**What I Learned:** How management frames are involved in wireless communication, why deauthentication attacks are possible, and how this informs stronger wireless network defense.

> ⚠️ This was conducted strictly as an authorized educational/security lab experiment. No attack instructions, tools, or operational steps are shared here — the focus is on the underlying security concept and defensive awareness.
