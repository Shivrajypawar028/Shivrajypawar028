## 🚀 Featured Projects

### 🎣 AI-Based Phishing Detection System
`Cybersecurity · AI/ML`

Phishing attacks rely on deceptive text to trick people into handing over sensitive information or clicking something they shouldn't. This project explores whether a model can catch that deception from the text alone.

Raw text goes through preprocessing and feature extraction, gets vectorized with **TF-IDF**, and is classified using **Logistic Regression** as potentially phishing or legitimate. Explainability was a deliberate focus — not just getting a prediction, but understanding *why* the model made it, rather than treating it as a black box.

- **Problem:** Phishing content is designed to look legitimate, making it hard for people to catch and harder to detect systematically.
- **Solution:** Apply text preprocessing, TF-IDF feature extraction, and Logistic Regression classification to flag likely phishing content.
- **Stack:** Python · Machine Learning · NLP · TF-IDF · Logistic Regression
- **What I learned:** How to preprocess and vectorize text, train and evaluate a classifier, and reason about model explainability in a security context.
- **Repo:** `[GitHub Repository Link]`

### 📡 Wi-Fi Deauthentication Attack — Security Experiment
`Cybersecurity · Networking — Educational`

An authorized lab experiment into how Wi-Fi deauthentication attacks exploit unprotected wireless management frames. The point wasn't to disrupt a network — it was to understand *why* this class of attack works and what it implies for defending one.

- **Problem:** Wireless networks can be disrupted by exploiting weaknesses in unprotected management frames.
- **Solution:** A controlled experiment studying how deauthentication attacks work and what they reveal about wireless network vulnerabilities.
- **Stack:** Networking concepts · Wi-Fi protocols
- **What I learned:** How management frames function in wireless communication, why deauth attacks are possible, and how that shapes stronger Wi-Fi defense.
- **Repo:** `[GitHub Repository Link]`

> ⚠️ Conducted strictly as an authorized educational lab experiment. No attack tooling, commands, or operational steps are shared here — this is about the concept and the defense, not the how-to.
